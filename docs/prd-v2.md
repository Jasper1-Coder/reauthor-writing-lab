# ReAuthor PRD v2 · 学生视角信息架构重构

> 版本 v2.0（信息架构重构，不改评分逻辑）· 立场：学生视角、不判罚、给证据 / 可修改 / 可申诉
> 触发：Eden 反馈"以用户视角看不够直接简单；HC3 / 数据集 / 协议对学生没用"。
> 本文件只做分析与规格；实现须继续遵守 `docs/prd.md` 的数据契约与红线（`src/lib/*` 评分逻辑只读）。

## 0. 事实基础（被重构对象速览）

| 位置 | 现状 | 学生视角问题 |
|---|---|---|
| App.tsx hero(56-68) | 全英文 kicker + 抽象标题"不该只剩一个 AI 百分比" + "透明加权公式 / 样本不足就拒判" | 第一屏全是概念与元叙事，没说清"我能得到什么" |
| Analyzer(118-226) | 英文 eyebrow、"先读文本再谈分数"、placeholder 塞满字数判定规则、4 步进度是技术工序 | 输入前就被规则和技术词劝退 |
| Results(179-358) | 分数环 → 2 条 calibration-strip → 5 张 metrics 权重卡 → 巨大 crosscheck 面板（含检索）→ 最后才是 5 tab | 首屏被 AUC/HC3/交叉验证淹没，找到"逐句/改写/申诉"要滚很久 |
| Results tab(361-367) | 顺序：逐句 / 改写 / 修改路线 / 判分依据 / 申诉 | 申诉排最后，最想要的入口最难找 |
| Methodology(340 行) | 6 大技术区块全文平铺（HC3/AUC/系数/跨域/红队） | 学生不需要读，却占满整页 |
| DefenseKit | 一页纸 + 4 步 + 导出齐全 | 功能对，但介绍语偏术语 |

**核心诊断**：信息按"我们如何证明自己严谨"排序，而不是按"学生此刻要解决什么"排序。

## 1. 用户画像与场景（Persona）

| # | 画像 | 场景 & 情绪 | 10 秒内能接受的信息 | 离开条件 |
|---|---|---|---|---|
| P1 | 小琳，本科生，被点名 | 课程论文被标 32% AI 率，导师让"解释"，明天要回复。恐慌、羞耻、委屈 | "这不是判决。先给你看哪几句被标、为什么、怎么改；一键生成给老师的说明" | 满屏 AUC/HC3，找不到"怎么跟老师解释" |
| P2 | 阿哲，主动改进型 | 作业未交，想让文章更有自己的声音。理性、想改、对技术好奇但没耐心 | "哪句空泛/套话 + 具体怎么改 + 改完能重测" | 先甩分数环和指标，无可操作的"改哪里" |
| P3 | Mia，留学生 / 研究生 | 英文非母语，怕"模板表达"被误判。紧张、语言弱势 | 中英双语、一句话说清问题 | 全英文 eyebrow + 中文技术黑话看不懂 |
| P4 | 争议申诉者 | 确信没用 AI 却被判高分，要据理力争。愤怒、要证据 | "给我能交给老师的 3 条证据 + 话术" | 找不到申诉入口，或觉得工具暗示"能骗检测"不可信 |

## 2. 竞品体验对比

| 工具 | 第一屏输出 | 是否解释 | 是否可申诉 | 学生痛点 |
|---|---|---|---|---|
| Turnitin | 相似度% + AI% 分数 | 有限（标红来源） | 走学校流程，工具内无 | 一纸分数定生死，无法反驳 |
| GPTZero | AI 概率分 + 高亮句 | 部分（哪些句像 AI） | 无 | 中文弱、误判难申诉 |
| ZeroGPT | 单一 AI% + 高亮 | 几乎无 | 无 | 误报高，"99%"不可信 |
| Pangram | "100% 确定"的 AI 分 | 无 | 无 | 黑箱，无法理解 |
| Grammarly | 质量分 + 逐句改写建议 | 强（逐句） | 不涉及 | 是润色助手，不解释"为何被判" |
| **我们（应然）** | **一句人话结论 + 哪几句值得看 + 从哪开始改** | **逐句证据 + 修改方向 + 公开边界** | **一键生成给老师的一页纸 + 申诉信** | **不再被动接受分数，能解释、能修改、能申诉** |

## 3. 信息架构重构清单（核心）

原则：**学生利益前置、技术依据默认收起**。所有"折叠"用原生 `<details>`，仅改展示层，不删功能 / 数据。

### 3.1 首页 hero + 导航（App.tsx 38-81）
- kicker(56)：删全英文 `STUDENT-OWNED WRITING FORENSICS...` → 中文短句"学生视角 · 不判罚 · 给证据"。
- 主标题(57)：推荐 **"被标了 AI？先把话说明白。"**（备选"你的文章，不该只剩一个分数"，保留原立意但更短）。
- 副标题(58)：利益点化——"3 分钟看清哪几句被标、为什么、怎么改，还能一键生成交给老师的说明。"
- CTA(60-61)：主按钮"看我的文章哪里被标了"（原"开始分析我的原稿"）；次按钮"没思路？先看样例"（原"先看判分依据"，避免一上来劝读技术）。
- hero-claims(63-68)："透明加权公式 / 样本不足就拒判"换成学生利益——"每句都能点开看依据 / 没把握就不下结论 / 原稿不离开你的电脑"；保留"逐句证据 + 修改方向""原稿不上传"。
- 导航(45)："评分方法"→"方法说明（选读）"；"学生宣言"保留。
- 视觉(70-79) annotated-paper 示例很直观，保留；privacy-chip 文案保留。

### 3.2 Analyzer 输入台（Analyzer.tsx 111-250）
- section-index(114) → "贴上你的文章"；eyebrow(118) 英文去除；h2(119) → "贴进来，我们逐句看"。
- placeholder(190)：只留一句"粘贴中文/英文文章，或拖入 PDF / Word / TXT"；字数判定规则移到输入框下方灰色小字或 `?` 折叠，不塞进 placeholder。
- 进度 stages(26)：技术工序 → 学生话："读你的文章 → 找出值得看的句子 → 给出依据和修改方向 → 生成报告"。
- 输入提示(225) → "至少写几句话，我们不对单句下结论。"；按钮(219) → "看看哪里被标了"。
- 保留：本地解析、文件导入、样本库、隐私角标"你的原稿只属于你"。

### 3.3 Results 结果页（Results.tsx，重点）
**第一屏（不滚动）只出现**：① 一句人话结论 `summaryFor`；② 分数环（保留但缩小、移到次位，配"不是概率，不判学术不端"）；③ 下一步引导"从哪句开始改？"直达逐句/改写；④ 待复核句数。`report-meta` 精简，"证据充分度"移入折叠。

**默认收起的技术 `<details>`（Results.tsx 227-358）**，summary = "想看分数怎么算的？展开技术依据（校准 / 权重 / 交叉验证）"，内部原样保留：
- 两条 `calibration-strip`(227-242)（AUC/HC3 披露）
- `metrics-grid` 5 张权重卡(244-256)
- 整个 `crosscheck-panel`(258-358)（含检索通道、分歧度）
> 只折叠、不删除：DOM 保留，供深读者与申诉证据引用。

**5 个 tab 重排 + 改名(361-367)**：
1. 逐句批注 → "逐句看：为什么被标"（默认）
2. 改写工作台 → "改一改：更像你的"
3. 申诉工作台 → "要申诉：给老师的说明"（由第 5 提至第 3）
4. 修改路线 → "修改清单"
5. 判分依据 → "分数怎么算的"
- 导出按钮组(172-176) 保留在标题区。`insufficient-banner`(214) 保留且前置（样本不足是重要提醒，不折叠）。

### 3.4 DefenseKit 申诉工作台（DefenseKit.tsx）
- 功能全保留；intro(132-134) 改人话："一个分数不该卡住你。这里把报告的证据整理成一页能交给老师的说明。"
- OnePager 标题(54) → "给老师看的 3 条证据"。
- 伦理红线横幅(139)、红线提醒(233-235) 原样保留；4 步结构、平台录入、写作过程自述、导出全部不动。

### 3.5 Methodology 方法页（Methodology.tsx）
- 顶部新增醒目提示："本页给想深挖的人；正常使用不用读——回到 [分析文章]。"
- method-lead 大段技术叙述(28) 收为 2-3 句"为什么做这个站" + "展开看完整方法论"。
- 6 大区块（#calibration / #redteam / #calibrated-model / #crossdomain / #retrieval / #source-ledger）**内容一字不删**，各包一层 `<details>`：默认只显示标题 + 一句学生话摘要（如自我校准："我们公开测过自己的准确率，结果并不漂亮"），展开看全部表格 / 系数 / 边界。
- manifesto(320-337) 保留。

## 4. 绝对不能删（红线清单）

- **功能**：分析 / 导入、逐句批注、改写工作台、修改路线、检索通道、导出（复制 / 打印 / 下载 MD）、申诉证据包（一页纸 + filled-in 信 + 下载 / 复制 / 打印）。
- **数据契约**（docs/prd.md）：`AppealPacket` 6 板块与全部口径常量（SINGLE_PERCENTAGE_CAVEAT / ETHICS_NOTICE / RETRIEVAL_NOTE / REWRITE_PLACEHOLDER / SELF_PLACEHOLDER / DEGRADED_NOTICE / ONE_PAGER_LINES）；`isSampleSufficient` 降级；`spread` 直接取不重算；`calibratedScoreMin/Max` 从 JSON 计算不硬编码；`src/lib/*` 评分逻辑只读。
- **隐私承诺**："原稿不上传 / 本地分析 / 不拿学生文本训练模型"——首页、输入台必须可见。
- **伦理红线**：不证明身份 / 不保证申诉成功 / 如实填写 / 不伪造 / 绝不暗示"能骗过检测器"。
- **透明立意**：分数可重算、系数与误差公开——可折叠，不可删。
