# ReAuthor · 重写权

**学生自己的 AI 写作特征诊断台** — 检测不是终审，解释才是起点。

> 我们需要的不是一张"像不像人"的判决书，而是一次解释自己的机会。

**🔴 在线使用：[jasper1-coder.github.io/reauthor-writing-lab](https://jasper1-coder.github.io/reauthor-writing-lab/)　·　[源码与评分常量](https://github.com/Jasper1-Coder/reauthor-writing-lab)　·　[版本变更记录](./CHANGELOG.md)**

针对 Turnitin、ZeroGPT、Pangram 式"判决式检测"的学生立场回应：不给你一个无法申诉的百分比，而是**逐句指出证据、解释判分依据、给出修改方向**——目标不是骗过检测器，而是让论证真正变成你自己的。

本站的"权威"不来自自称，而来自三件可验证的事：**训练数据公开、测试协议公开、每一个系数和边界公开**。任何人都能按 [方法](#-方法论双层模型与边界) 复现我们的数字，也能据此质疑我们。

## 📊 一句话看懂我们的成绩

| 通道 | 数据 | 留出折 ROC AUC | 我们自己的评价 |
| --- | --- | --- | --- |
| 手调规则引擎 | HC3 中文 480 篇 | **0.515** | 接近随机。保留它只为逐句解释能力，**不作为判分依据** |
| 校准模型（v0.5） | HC3-Chinese 3826 篇，分层 5 折 | **0.930 ± 0.007** | 灵敏度 81% / 特异度 90%，有公开误差数据，是训练域内主推的可信读数 |
| 校准模型·**跨域**（v0.5.1） | 真实中文期刊摘要（DeepSeek 改写） | **0.859** | 换领域、换生成器后下降但仍有序；绝对分数塌缩、固定阈值失效，**已如实公开** |
| 规则引擎·跨域（v0.5.1） | 同上 | **0.223** | 低于随机、方向颠倒——这是 v0.5 起不再让它主导判分的实证 |
| **语料基座检索（v0.7）** | HC3 中文 6010 段真实问答，字符 bigram TF-IDF 最近邻 | **0.986**（域内留出） | **零 AI 模型**的最强信号；但跨域学术 AUC 仅约 0.53，通道会显示"基座匹配度低"并降级为定性参考，**已如实公开** |

这些数字看似矛盾，实则是本站最重要的诚实：**我们不是把规则调得"看起来准"，而是用受检验的模型/大语料替换了它，并把替换前后的真实成绩、包括跨域时的难看表现都摊开。** 商业检测网站不会告诉你它们的对应数字。

## 🧭 设计立场

1. **证据先于结论** — 每个分数都能点开看证据，可以不同意，也可以复核。
2. **不确定就弃权** — 短文本不给定性，这是刻意的保守，不是能力缺陷。
3. **修改而非规避** — 不提供"降 AI 率"的一键洗稿，建议全部指向论证、证据与风格。
4. **权威来自可复现** — 不靠"99% 准确"的自我宣称，靠公开数据、协议、系数与边界。
5. **诊断必须通向行动** — 只给分数不给"怎么动手"是半成品；改写工作台让学生自己改、即时复测、拿过程证据去沟通。
6. **不迷信大模型** — 查重的本质是"与参照基座比对"，不是非得跑 AI。语料检索通道用纯统计方法（字符 bigram TF-IDF 最近邻）在域内达到 AUC 0.986，比任何神经方案都强，且零下载、可解释、能列出最近邻原文供核对。

## 🔬 方法论：双层模型与边界（重要）

本站有三套并行读数，用途不同，不可混淆：

- **手调规则引擎（rules-v0.2）**：五维加权的可解释分数。**它在 HC3 中文数据集上的 ROC AUC ≈ 0.515（接近随机）**。我们保留它是因为它能逐句解释"哪里像模板、怎么改"，而不是因为它能判别作者。主分数中的这一层只作反馈，不用于定性。
- **校准模型通道（v0.5）**：8 个表层文体特征 + L2 逻辑回归，在 [HC3-Chinese](https://huggingface.co/datasets/Hello-SimpleAI/HC3) 上以分层 5 折交叉验证训练，留出折 AUC 0.930 ± 0.007。**这是本站有公开误差数据的读数之一**，但它回答的只是"这段文本与训练集中 AI 文本的特征分布有多相似"，仍不是作者身份判定。
- **语料检索通道（v0.7）**：不做任何训练或推理，只做最近邻检索——6010 段真实问答语料向量化后，看你的文本最像其中哪 15 段、它们是人写还是 AI 写。**域内留出 AUC 0.986，是全站最强信号，且零模型、零联网、最近邻原文可逐条核对**。它把"AI 率"变成一个可检查的证据问题，而不是一个黑箱数字。

### 不可越过的边界

- 训练域是 **2023 年 ChatGPT 生成的问答文本（HC3-Chinese）**，不是学术论文。**v0.5.1 的跨域验证已把这个"可能偏移"量化**：在真实中文期刊摘要 + DeepSeek 改写上，校准模型 AUC 降到 0.859、绝对分数整体塌到 0–18、线上阈值 50 的灵敏度为 0%；规则引擎更是 AUC 0.223 方向颠倒。详见方法页与 `src/data/crossDomainValidation.json`。
- 语料检索通道同样受领域偏移影响：跨域学术文本 AUC 仅约 0.53，近邻几乎全被判成 AI。因此它会显示"基座匹配度低"并降级为定性参考——**不要把它在学术文本上的高分当真**。
- 表层特征模型对彻底洗稿依然脆弱（见方法页红队测试）；它们有公开的误差数据，但没有免死金牌。
- 非母语写作、规范学术文体、翻译文本可能出现类似特征，**不得用于推定作者身份或学术不端**。
- 结果应服务于作者自我修改与师生对话，**不应作为处罚依据**。

### 可复现管线

```bash
npx tsx scripts/train-model.ts     # 重训校准模型（HC3-Chinese，5 折 CV）
npx tsx scripts/calibrate.ts       # 手调规则引擎的 HC3 自我校准
npx tsx scripts/redteam-model.ts   # 红队改写攻击复测
npx tsx scripts/crossdomain-test.ts # 跨域验证（问答训练 → 学术摘要测试）
npx tsx scripts/retrieval-probe.ts       # 向量检索可行性实验（零 AI，域内+跨域）
npx tsx scripts/build-retrieval-index.ts # 重建检索基座索引 → public/retrieval-index.json
```

所有系数、均值、标准差与 CV 指标落在 `src/data/calibratedModel.json`，与页面展示同源。
